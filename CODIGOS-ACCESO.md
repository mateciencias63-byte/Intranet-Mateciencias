# Códigos de Acceso - Canvas Studies

## Instrucciones
Cada tarjeta en Canvas Studies requiere un código de acceso de 6 caracteres con formato: **XXX-XXX**

Al hacer clic en cualquier tarjeta, se abrirá un modal solicitando el código. Los códigos son **complejos y alfanuméricos** (letras y números combinados).

## Características del Sistema

✅ **Validación de código alfanumérico** - Los códigos combinan letras y números  
✅ **Formato automático** - El código se formatea automáticamente (XXX-XXX)  
✅ **Validación en tiempo real** - Presiona Enter o haz clic en "Acceder"  
✅ **Mensajes de error** - Si el código es incorrecto, muestra error y borra el campo  
✅ **Modal amigable** - Interfaz clara y fácil de usar  
✅ **Cierre flexible** - Puedes cerrar el modal haciendo clic fuera o en "Cancelar"
