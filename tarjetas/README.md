Los módulos de Docentes se reutilizan desde Administración; no se duplican. Encuestas conserva el módulo compartido `admin-extras.js`. Trámites abre el módulo de Secretaría. Los materiales están agrupados en `MATERIAL 1/`; el logo, los estilos y los servicios generales permanecen compartidos en la raíz.

`rutas.json` registra la ubicación anterior y nueva de cada archivo.
