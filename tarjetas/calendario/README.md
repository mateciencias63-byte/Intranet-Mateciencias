# Calendario

La tarjeta principal **Calendario** abre directamente la agenda del Aula Virtual, sin inicio de sesión. Usa el mismo componente `calendario-aula.js` y los mismos eventos (`matecienciasCalendario`).

Entrada: [calendario-academico.html](calendario-academico.html).

Las páginas usan `<base href="../../">` para acceder a los recursos compartidos de la raíz.

La vista permite consultar eventos y cambiar de mes. El botón de regreso lleva a `dashboard.html`. La dirección anterior `calendario-login.html` redirige a la vista pública.
